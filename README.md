# 4REAL GLOBAL IT SOLUTION Website + Registration

Responsive website plus applicant registration and Firebase/Firestore backend.

## Registration fields
1. First name
2. Surname
3. Email address
4. Phone number
5. Institution type (University / Polytechnic)
6. Institution / School (dependent list)
7. Department
8. Program (SIWES / IT / DIPLOMA)
9. Previous course/stack
10. Reason for choosing the course

Successful submissions receive a registration number. Firebase Cloud Functions can send the confirmation email.
